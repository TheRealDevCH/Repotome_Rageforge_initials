What is this?

The Rageforge Mirror Cube is a Minecraft block that reflects on all six of its faces at once. Place it down and it acts like a real mirror in every direction — you can see the world, mobs, and blocks around it, but not yourself. Two cubes facing each other create a striking infinite-mirror effect.

It's built on top of the excellent Mirror mod by Isaac Harper (MIT license), extended by Rageforge with the full six-sided cube, a dedicated "Rageforge" creative tab, and a few tweaks.

⚠️
Heads up: this mod is heavy on performance.

Real-time reflections mean the game re-renders parts of the scene for every mirror face on screen, on top of everything already being drawn. Depending on your settings and hardware this can noticeably drop your FPS, especially with multiple cubes visible at once or high recursion depth.

The good news: you're in control. All performance-relevant values live in config/mirror.json — turn them down for smooth gameplay on weaker PCs, or crank them up if your rig can handle a more accurate, deeper reflection.

Requirements

  • Minecraft Java Edition 26.2
  • Fabric Loader 0.19+
  • Fabric API for 26.2

Installation

  1. Install Fabric Loader for Minecraft 26.2.
  2. Download Fabric API and put it in your mods folder.
  3. Copy the mod jars from this repo's mods/ folder into your mods folder.
  4. Optional: copy config/mirror.json into your config folder to pre-tune performance settings.
  5. Launch the game.

How to use it

  • Open the Rageforge creative tab.
  • Place the Mirror Cube — a full block, all sides reflective.
  • The classic wall-mounted Mirror block is also available in the same tab.
  • Place two mirrors facing each other for an infinite-mirror effect.

Performance settings (config/mirror.json)

Edit this file to balance visual quality against FPS. Lower values = better performance, higher values = better/deeper reflections but more GPU/CPU load. 

{
  "maxReflections": 10,
  "recursionDepth": 4,
  "nestedPerParent": 2,
  "maxRenderPasses": 48,
  "reflectionDistanceChunks": 10,
  "fogStartBlocks": 100,
  "resolutionScale": 0.85
}
SettingWhat it doesLower it if…
maxReflections Maximum number of mirror surfaces rendered at once. You have many mirrors visible and get low FPS.
recursionDepth How many times a mirror can reflect into another mirror (mirror-in-a-mirror). Higher = closer to a true infinite mirror. Two facing mirrors tank your framerate.
nestedPerParent How many nested reflections are allowed per parent reflection. Complex reflection setups feel laggy.
maxRenderPasses Hard cap on total render passes spent on reflections — the overall performance budget. You want a strict FPS safety net regardless of other settings.
reflectionDistanceChunks How far (in chunks) the reflected view extends. Reflections of distant terrain aren't important to you.
fogStartBlocks Distance at which fog starts fading in the reflection, hiding far-away render cost. You want reflections to fade out sooner to save performance.
resolutionScale Render resolution of the reflection relative to your normal resolution (1.0 = full quality). You need the single biggest FPS win — this has the most impact.

Tip: if the mod feels heavy, start by lowering resolutionScale and recursionDepth first — they usually give the biggest performance gains for the smallest visual trade-off.

Compatibility

  • ✅ Works with Sodium — the mod temporarily redirects Sodium's terrain rendering into the mirror's view during a reflection pass, then restores it.
  • ❌ Not compatible with Iris — Iris replaces the render pipeline that the reflection pass relies on.
